# نظام إدارة العمولات

## نظرة عامة

نظام متكامل لإدارة وحساب عمولات الفروع والمشرفين، مع تحليلات متقدمة وأدوات تحسين الأداء.

## الميزات الرئيسية

### 1. لوحة التحكم المتقدمة
- عرض إحصائيات شاملة للمبيعات والعمولات
- رسوم بيانية تفاعلية للمقارنة بين الأعوام
- متابعة تقدم المعالجة
- إشعارات فورية

### 2. محسن العمولات (Commission Optimizer)
- تحليل فرص تحسين العمولات
- اقتراح معدلات عمولة محسنة
- محاكاة تأثير التغييرات المالية
- تقييم مستوى المخاطر
- حساب تأثير الحافز على الأداء

### 3. محلل أداء الموظفين (Employee Performance)
- تتبع أداء مديري الفروع
- مقارنة الأداء بين الموظفين
- عرض الإنجازات والأهداف
- تحليل نمو العمولات
- تصنيف الموظفين حسب الأداء

### 4. إدارة البيانات
- رفع ملفات Excel للمبيعات
- مقارنة بين سنوات متعددة
- التعامل مع الفروع الجديدة والجزئية
- أرشفة البيانات التاريخية

### 5. التقارير والتحليلات
- تقارير مفصلة لكل فرع
- ملخصات للمشرفين
- تصنيف الفروع حسب الأداء
- تحديد الفروع التي تحتاج انتباه

## المكونات الرئيسية

### المكونات الموجودة في `components/ui/`

1. **stats-card.tsx**: بطاقة إحصائيات مع مؤشرات التغيير
2. **simple-chart.tsx**: رسم بياني بسيط للمقارنات
3. **notification-panel.tsx**: لوحة الإشعارات
4. **progress-tracker.tsx**: متابعة تقدم المعالجة
5. **commission-optimizer.tsx**: محسن العمولات
6. **employee-performance.tsx**: محلل أداء الموظفين

## الاستخدام

### إضافة البيانات

1. انتقل إلى صفحة العمولات
2. انقر على "رفع وتحديث البيانات"
3. اختر الشهر والسنة
4. ارفع ملف Excel الذي يحتوي على بيانات المبيعات

### تحليل العمولات

1. بعد رفع البيانات، ستظهر لوحة التحكم المتقدمة
2. استخدم محسن العمولات لتحليل فرص التحسين
3. راجع أداء الموظفين في قسم محلل الأداء
4. قارن النتائج بين الفروع والمشرفين

### محاكاة التغييرات

1. في قسم محسن العمولات
2. اختر القاعدة التي تريد تحليلها
3. قم بتعديل معدل العمولة
4. راجع التأثير المالي المتوقع

## البنية التقنية

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Data Processing**: XLSX (Excel)
- **Backend**: Supabase

## المسارات الرئيسية

- `/commissions`: صفحة إدارة العمولات الرئيسية
- `/commissions/upload`: رفع وتحديث البيانات
- `/commissions/dashboard`: لوحة التحكم المتقدمة
- `/commissions/results`: عرض النتائج والتحليلات

## البيانات المطلوبة

### ملف Excel المبيعات

يجب أن يحتوي الملف على الأعمدة التالية:
- اسم الفرع
- المبيعات (للعام الحالي والسابق)
- معلومات المشرف
- حالة الفرع (جديد/جزئي/عادي)

## التخصيص

### تعديل قواعد العمولات

يمكن تعديل قواعد العمولات في ملف `lib/commission-utils.ts`:
- معدلات العمولة الأساسية
- عوامل النمو
- حسابات المشرفين
- معايير التقييم

### تخصيص الواجهة

يمكن تخصيص الواجهة عن طريق تعديل المكونات في `components/ui/`:
- الألوان والأنماط
- التخطيط والتنظيم
- الرسوم البيانية
- الإشعارات
